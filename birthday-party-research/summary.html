1. 结论摘要

要回答的问题：应该打造哪些核心服务？依据是什么？

1.1 核心服务清单（初判，2 批次）

判断 服务 依据
🟢 优先打造 生日照 / 拍照打卡 两批一致：都把拍照出片当作评价生日服务的第一标准。模板偏好分人群，「粉色派对」和「头版头条」「喜报」「特此通知」这类公文或新闻梗模板，两批都给了好评
🟢 优先打造（先验证付费） 包厢实体布景 两批一致：扣分都和「现场没有实体装扮、出片不如餐厅」有关。第 3 批女寿星主动给出 39.9 / 69.9 / 99.9 元三档价格，需要真实下单验证

⏳ 未覆盖 搞怪 pose、蹦迪狂欢 两批都没有单独聊到，下一批需要逐项补问

1.2 关键发现

  1. 出片是生日服务的第一评判标准，两批的扣分也都扣在出片上。（两批一致）第 1 批氛围满意度 7.5 / 10，认为出片和适用面不如餐厅、素材不够惊艳；第 3 批整场满意度 8.0 / 10，2 分全扣在「缺少实体装扮」和「拍照灯光不好」上。注意：两批问的满意度题目不同（氛围满意度 / 整场满意度），两个分数不能直接比较。
  2. KTV 在生日动线里是晚饭的补充，不是主场。（两批一致）「生日 = 晚饭」，主环节在餐厅：第 1 批习惯先唱歌再吃饭；第 3 批平时是餐厅过完生日再来 KTV 续摊，这次是先唱后吃。两批都提到餐厅的生日服务是免费的（摆台、气球、唱生日歌），这是用户心里的对照基准。
  3. 付费意愿分人群：女生出片局愿意付，学生和男生局基本不付。 第 1 批学生「免费提供才考虑」；第 3 批女寿星愿意为布景付费，心理上限 100 元以内，建议分 39.9 / 69.9 / 99.9 元三档，但同时提醒纯男生局几乎不会为布置加钱。目前只有 1 位受访者给出具体价格，需要验证。
  4. 拍照灯光两批都是负面评价，问题是「光不对」，不是画面本身。（两批一致）第 1 批说白光直射「像坐在教室里」；第 3 批说蓝光和紫、粉、红等深色光很不上相，而且歌曲一暂停灯光就锁住不变。两批诉求一致：暖色柔光，第 3 批还想要只打在蛋糕或礼物上的筒灯追光。
  5. 拍照模板的审美分人群，不存在一套通用排序。 「椰树」被第 1 批学生列为必留（有梗、抽象），却被第 3 批女生评为「欠打」；第 3 批最喜欢的是会自动配灯的「黑影 / 剪影」模式（拍照不露脸，有氛围感）。
  6. 每一批都被一个阻断性 Bug 拉低体验。（两批一致）第 1 批疯狂猜词卡死；第 3 批定制氛围提交失败、现场报 110 错误，进门核心仪式没能播放。
  7. 内容更新能带来复购和转介绍。 第 3 批受访者是第二次来嗨瓣，之前已带朋友来过；明确表示如果每 1–2 个月更新玩法和模板还会再来。第 1 批则提醒：生日离得近的朋友不会连续来，新鲜感会衰减。

1.3 行动建议（立即可做）

  • 修复定制氛围提交失败和扫码绑定包厢报 110 错误，确保预订时设置的欢迎氛围到店就能播放。
  • 确认疯狂猜词卡死是否已修复；没有修复的，继续作为 P0。
  • 拍照模式提供暖白光 / 暖色柔光预设，并修复「歌曲暂停后灯光锁死」。
  • 小范围试推 39.9 / 69.9 / 99.9 元三档布景包，记录真实下单情况。
  • 下一批起当场回收逐项评分问卷，并按原题问 U8（只保留 3 项），补齐两批都缺的评分和取舍数据。

3.2 用户凭什么判断「办得好」（价值权重）

  1. 出片（两批一致）：拍照效果是第一位。第 1 批：「环境不是很重要，人要好看。」第 3 批：女生来包厢过生日，核心目的就是拍照、出片、留合照。
  2. 进门第一印象 / 惊喜感（两批一致）：第 1 批以海底捞每次摆台都不一样为例；第 3 批肯定欢迎仪式，但希望内容不要「千篇一律」，能写进寿星姓名、到场朋友和想说的话。
  3. 全员都能参与：互动玩法要人人都能直接加入，不能让人尴尬（第 1 批）。
  4. 自由度和基础体验：可以自带酒水、点外卖进包厢、音质好，是第 3 批选嗨瓣的基础理由。

3.4 难忘时刻

  • 🟢 生日照：第 1 批记住了「椰树」背景（有梗、抽象，想发朋友圈）；第 3 批最喜欢「黑影 / 剪影」模式，选中后灯光会自动配合。
  • 🟢 歌王争霸赛（第 3 批）：寿星当场唱到本店第一，惦记晚上还要守擂。
  • 🔴 蛋糕仪式：第 1 批完全没有印象。
  • 🔴 定制氛围：第 3 批提前准备了，结果进门没能播放。

3.5 价格感知

  • 自助 K 的价格锚点：约 20–30 元 / 小时，下午场和夜场差别不大（第 1 批）。
  • 免费基准：餐厅的摆台、气球、生日歌都是免费的；只有鲜花布置要额外付费（两批）。
  • 透明比价：用户很清楚网上自购 KT 板 + 气球 的成本（订婚、满月、周岁都常见自己买），定价超过 100 元或者显得廉价，会马上引起抵触（第 3 批）。
  • 付费意愿：
  • 第 1 批学生：「如果是免费提供，而且真的让我满意，我肯定会考虑。」
  • 第 3 批女寿星：愿意为布景付费，心理上限 100 元以内，建议 39.9 / 69.9 / 99.9 元三档（普通 / 高级 / 豪华），99.9 元档必须「很豪华」（大量反光气球、丰富花束、公仔或布景卡等全套摆台）。
  • ⚠️ 纯男生局几乎不会为布置和拍照加钱（第 3 批受访者的判断）。
  • ⏳ 付费决策人、触摸屏玩法的单独购买意愿，两批都没问到。

6. 机会与陷阱

要回答的问题：还有哪些未满足的需求？哪些好指标其实有风险？

6.1 愿望清单（用户主动提出）

  • 定制欢迎内容：展示合影而不是寿星单人照（第 1 批）；填寿星姓名、到场朋友和想说的话，由 AI 生成专属欢迎词和画面（第 3 批）。
  • 暖色柔光和局部追光：美颜柔光（第 1 批）；暖白光模式，加上只打在蛋糕或礼物上的筒灯，可以用手机或 AI 小助手控制（第 3 批）。
  • 实体布景：反光铝箔气球、「生日快乐」背景墙、花束（第 3 批）；赠送小蛋糕来烘托氛围（第 1 批）。
  • 新拍照模板：派对主题、变装派对（第 1 批）；「锦旗风」、亲子 / 家庭模板（第 3 批）。
  • 玩法可以自定义：「寿星的指令」让朋友写自己的梗和惩罚；「动起来」加手机体感（第 3 批）。
  • 偶像相关：idol 出现在屏幕上送祝福；K-pop 打歌舞台 / 虚拟舞台，按成员分配站位、屏幕上的成员补位（第 1 批）。

6.3 交叉信号与陷阱

  • ⚠️ 满意度高不等于会选这里。 两批都把餐厅当作过生日的主场，KTV 是补充；第 1 批还说「想玩疯一点会在家里」。
  • ⚠️ 8.0 分来自一位回头客。 第 3 批受访者本来就喜欢嗨瓣、已经带朋友来过，分数可能偏高，需要更多新客样本。
  • ⚠️ 两批满意度口径不同。 7.5 是氛围满意度，8.0 是整场满意度，不能说「满意度在上升」。
  • ⚠️ 99.9 元是心理上限，比价很透明。 用户知道自购 KT 板和气球很便宜，免费气球的餐厅就在旁边；布景包必须让人一眼看出「比自己买的好、比餐厅送的好」。
  • ⚠️ 付费意愿分人群。 女生局愿意付，学生「免费才考虑」，男生局几乎不付；不能用一个人的报价推算整体付费率。
  • ⚠️ 模板审美分人群。 「椰树」在一批里是必留、在另一批里是差评，按单批反馈直接删模板有风险。
  • ⚠️ 「会用」「会再来」都是口头意愿，需要真实场次、下单和复访数据验证。
  • ⚠️ AI 增强吸引人，但有隐私风险：第 1 批担心人脸被上传；第 3 批也是因为隐私原因，包厢不能装摄像头。推得越重，信任成本越高。
  • ⚠️ 复购的新鲜感会衰减。 第 3 批的复访承诺以「1–2 个月更新一次」为前提，内容更新要成为固定投入。

7.2 待验证清单

  1. 真实生日场次中，仪式类服务（蛋糕、生日歌、祝福）的感知是否明显提升？第 3 批是真实场次，但蛋糕在访谈时还没切，仍缺证据。
  2. 「只保留 3 项」（U8）的排序：生日照、猜词、布景是否稳定排在前列？
  3. 定制氛围修好后，完整播放一次的真实效果和惊喜感如何？
  4. 39.9 / 69.9 / 99.9 元布景包的实际下单率，女生局、情侣、男生局、家庭局分别如何？和免费气球的餐厅相比优势在哪？
  5. 拍照模板偏好是否按年龄、性别、职业稳定分化（如「椰树」）？
  6. 搞怪 pose、蹦迪狂欢的评价。
  7. 新客和回头客的满意度差异（第 3 批是回头客）。
  8. 门店侧：执行负担、店员依赖、门店之间的差异。

7.3 与 K 前引流的衔接

  • 用户选 KTV 时看性价比和团购，信息来自抖音（第 1 批）。生日服务适合作为团购套餐的差异化卖点，三档布景包可以做成团购加购项。
  • 定制氛围的惊喜感依赖提前预订并上传素材；第 3 批恰恰卡在这一步，所以预订环节（①②）的稳定性直接决定到店第一印象。
  • 预订时按人数提示包厢大小，避免 5–6 人订到 3–4 人的小包厢。
  • 「零点生日局」可以单独作为一个引流产品来测试。
